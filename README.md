🤖 AI Chatbot - Frontend Project
A beautiful, modern AI chatbot interface powered by Claude API. This is a frontend-only project with everything ready for backend developers to integrate their own API endpoints.
🎨 For Frontend Developers
This project is 100% frontend - just HTML, CSS, and vanilla JavaScript. No backend setup required on your end! Simply update the API endpoint in settings to connect to your backend service.
🔧 For Backend Developers
All the frontend is ready to go! Just build your backend API endpoint that:

Accepts POST requests to /api/chat
Receives: { message: string, conversationHistory: array }
Returns: { response: string }

That's it! The frontend handles everything else.
